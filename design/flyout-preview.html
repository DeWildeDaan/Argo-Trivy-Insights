KSV110

Container should not be running in privileged mode

CRITICAL Kubernetes Security Check Deployment/payments-api
Description

A privileged container has all root capabilities of a host machine and can also grant access to devices. This allows the container to gain almost all the same access as processes running directly on the host.

Messages
  • Container 'payments-api' of Deployment 'payments-api' should set 'securityContext.privileged' to false
  • Default value for 'securityContext.privileged' is false
Remediation

Set 'containers[].securityContext.privileged' to false in the pod spec, or omit the field entirely so it defaults to false.
